# Waystones, tablets, atlas

Source of truth: `notes/atlas-tablets-maps.md`. It holds the generated tables (section G, never hand-edit), the stacking rules and the fast-pick. Tags: [V] game data, [S] secondary source, [E] estimate, [U] unknown. Carry the tags into answers.

## Model a combination in the engine
Eval cwd is `PathOfBuilding-PoE2/src`:
```
node tools/pob.mjs <build.xml> "eval:local C=dofile('../../tools/content.lua') C.compose{tier=16, waystone={...}, tablets={...}, atlas='all'} return C.metrics()"
```
- `C.list('pieces')` lists the valid waystone, tablet and atlas ids.
- Named profiles: `C.apply('t16_6mod_irr3')`. Reset: `C.apply('reset')`.
- `C.metrics()` returns EHP, the death clock, main-skill DPS, kill time and the reward multipliers (waystones, rarity, pack size, magic/rare, effectiveness).
- Worked example: `.work/atlas_fastpick.lua`.

## Rules
- All numbers come from the game data (`tools/content_data.lua`, generated by `tools/gd_atlas.py`). Never type a game number into `content.lua`. Non-data numbers go only in `C.EXTERNAL`, with source, date and patch.
- What PoB cannot model: monster speed, curses on the player, ground effects, ailment buildup, armour break, flask charges, the rare monster mod pool. When one matters, say so. Do not report "0% change" as "safe".
- Hidden reward stats are "% more" and multiply. Effectiveness adds monster toughness, XP and quantity, not damage.
- Atlas nodes that scale waystone or tablet effect also scale the danger.
- Verify after edits: `node tools/pob.mjs builds/monk-cur-calc.xml "eval:$(cat tools/checks/content_check.lua)"` must return ok=true. New patch: see the poe2-patch-day skill (`--diff` mode).
